A Python 3.13 standard-library program that writes one deadpan one-star review of an everyday essential — gravity, filed as a consumer complaint — to `/output/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The output directory defaults to `/output`. The program creates it when needed, and fails loudly if the review ever stops meeting the gate (1–160 characters, one line, not only white space).
